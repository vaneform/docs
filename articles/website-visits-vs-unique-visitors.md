# Website visits vs unique visitors: how to read both

Originally published at <https://vaneform.com/guides/website-visits-vs-unique-visitors> on 2026-10-08 by Kai · 中文版: <https://vaneform.com/zh/guides/website-visits-vs-unique-visitors>

## Summary

A report showing 100,000 monthly visits leaves an important question open: how many people came? This guide explains visits (sessions), unique visitors and pageviews with one worked example, and shows how each measurement system defines them differently, so the same word can mean different things across tools and analytics products.

Two illustrative cases make the point. If visits rise while the visitor count stays flat, the same people are coming back more often. And two months with identical visitor counts can contain very different people: in the example, only 20% of the first month's visitors return. Adding up daily visitors also changes the question, because someone who shows up on ten days is counted ten times. The guide closes with a decision table that matches the metric to the job: same-month visits for picking a competitor to study, consistent unique visitors for campaign reach, cohorts for retention, and task completion for support pages.

## Key points and data

- Illustrative month: 20,000 unique visitors, 50,000 visits and 150,000 pageviews.
- Visits can rise to 75,000 while visitors stay at 20,000, which signals repeat use rather than new reach.
- Equal visitor counts can hide turnover; in the example only 20% of first-month visitors return.
- Summing daily visitors counts a returning person once per day.
- When both metrics come from one report, visits per visitor is a useful derived ratio.
